RoleRun Manager v0.2.2-alpha.132

Esta versión recupera en el diseño nuevo la señal visible de movimientos
incompatibles con el rol. La tarjeta de Equipo los muestra en rojo y la ficha
del Pokémon ofrece las acciones para sustituirlos por una MT o eliminarlos.

No se generan ZIP ni copias paralelas: esta versión se ejecuta directamente
desde el repositorio de desarrollo.
