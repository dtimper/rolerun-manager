ROLERUN MANAGER v1.9.0-alpha.3
================================

Esta versión mantiene el funcionamiento de v1.9.0-alpha.2 y añade un aviso específico para Pokémon Blanco / Negro al pulsar Guardar cambios.

Con guardados .dsv de DeSmuME:
- La forma más consistente de aplicar los cambios es cerrar y volver a abrir el emulador.
- También se puede probar a pulsar Reset varias veces hasta que RoleRun Manager detecte la ventana de reinicio.
- No se ha cambiado la lógica de guardado ni la compatibilidad del resto de juegos.
