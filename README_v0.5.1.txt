RoleRun Manager v0.5.1-dev

Novedad principal: cola de cambios pendientes.

- Los drafteos ya no escriben inmediatamente el guardado.
- Cada drafteo se añade a una previsualización en memoria.
- La barra superior muestra cuántos cambios están pendientes.
- REVISAR CAMBIOS permite consultar y quitar cambios individuales.
- DESCARTAR recupera el último estado guardado.
- GUARDAR CAMBIOS crea un único backup, aplica todos los cambios y valida el archivo final.

Instalación: copiar sobre la carpeta actual conservando .git. No es necesario recompilar el motor.
