RoleRun Manager v0.4.1-dev

Esta actualización corrige el diagnóstico del migrador de movimientos.

INSTALACIÓN
1. Copia el contenido sobre tu carpeta actual conservando .git.
2. Ejecuta preparar_motor.bat.
3. Si falla la migración, se abrirá automáticamente:
   logs\migration_moves_v041.txt
4. Envía ese informe completo para revisar las entradas no reconocidas.

IMPORTANTE
- El migrador no inventa nombres ni traducciones.
- data\moves.json solo se sustituye si todas las entradas son válidas.
- Los errores técnicos y los nombres no reconocidos aparecen diferenciados.
