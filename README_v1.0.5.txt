ROLERUN MANAGER v1.0.5
========================

Versión interna de arquitectura. Para el usuario mantiene exactamente el mismo
funcionamiento que la v1.0.4.

CAMBIO PRINCIPAL
----------------
- Se ha creado un contrato común de motores de juego.
- BDSP funciona ahora como el primer plugin oficial.
- La interfaz, las Runs, OBS y los drafteos ya no dependen directamente del
  formato de Diamante Brillante / Perla Reluciente.
- La base queda preparada para añadir Ultra Sol / Ultra Luna en la v1.1.0.

No es necesario recompilar el motor de guardados.
