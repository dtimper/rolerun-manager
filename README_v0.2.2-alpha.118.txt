RoleRun Manager v0.2.2-alpha.118
================================

La primera apertura de una Run BDSP mantiene una pantalla de carga maximizada
y animada hasta que los PS live, las cajas y la interfaz final están asentados
en la geometría real de la ventana.

La aplicación ya no publica el relayout intermedio de Windows: el último frame
de carga da paso directamente a Equipo y PC completamente construido.

No se añaden direcciones RAM ni escrituras nuevas.
