ROLERUN MANAGER v0.2.0-dev
===========================

OBJETIVO DE ESTA VERSION
- Mantiene el generador de drafteos.
- Mantiene los backups verificados.
- Añade el primer motor de lectura basado en PKHeX.Core.
- Intenta identificar el juego y mostrar los Pokémon del equipo sin modificar el guardado.

PRIMERA PREPARACION
1. Instala el SDK x64 de .NET 10 desde Microsoft.
2. Ejecuta preparar_motor.bat.
3. Cuando indique que terminó correctamente, ejecuta instalar_y_abrir.bat.
4. Abre "Partida guardada" y selecciona una COPIA del guardado.

SEGURIDAD
Esta versión es de solo lectura. No contiene ninguna orden para escribir o reemplazar el guardado.
