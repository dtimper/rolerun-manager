ROLERUN MANAGER v1.2.0-alpha.3
================================

CAMBIO PRINCIPAL
----------------
OBS utiliza ahora una única carpeta permanente:

Documentos\RoleRun Manager\OBS

Todos los juegos y Runs escriben sobre los mismos archivos de salida. Al abrir
otra partida, vidas, curaciones, medallas, drafteos, sprites y roles se
actualizan automáticamente. Configura las fuentes de OBS una sola vez.

MIGRACIÓN
---------
Las carpetas antiguas OBS\ACTIVO, OBS\BDSP, OBS\USUM y OBS\SM se unifican
automáticamente. La información persistente de cada Run continúa guardada en
Documentos\RoleRun Manager\Runs.
