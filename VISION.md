# Visión

RoleRun Manager debe ser el compañero central de una RoleRun, no un conjunto de parches por juego. El objetivo del Real-Time Core es que UI, reglas, OBS, automatismos, diagnóstico y replay funcionen de forma idéntica independientemente del juego o emulador. Cada plataforma solo debe aportar un bridge de memoria y cada juego un adaptador capaz de traducir su estado al contrato común.
