ROLERUN MANAGER v0.7.2
========================

Cambios de esta versión:
- El contador visible POCIONES pasa a llamarse CURACIONES.
- Nuevo icono médico para el contador de curaciones.
- Los atajos se muestran como Sumar/Restar curación.
- Los eventos del Hub usan la palabra curaciones.
- OBS utiliza curaciones.txt y elimina automáticamente el antiguo pociones.txt.

Compatibilidad:
- El valor existente de pociones se conserva durante la actualización.
- Los atajos previamente asignados siguen funcionando.
- No hace falta volver a preparar el motor.
