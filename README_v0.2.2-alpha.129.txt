RoleRun Manager v0.2.2-alpha.129

Esta versión añade en UltraSol/UltraLuna el arrastre seguro de Pokémon entre
cajas del PC: mantén la criatura sobre una flecha para cambiar de caja y suéltala
en una casilla vacía concreta. La operación usa preflight, readback y rollback.

No se generan ZIP ni copias paralelas: esta versión se ejecuta directamente
desde el repositorio de desarrollo.
