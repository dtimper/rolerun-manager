ROLERUN MANAGER v1.5.0-alpha.1

NOVEDADES
- Soporte experimental para Pokémon Blanco 2 / Negro 2.
- Admite guardados .sav y .dsv de DeSmuME.
- Los .dsv conservan automáticamente su cabecera/footer de DeSmuME al guardar.
- Nueva utilidad DINERO MÁXIMO para todos los juegos compatibles.
- Mantiene drafteos, roles, OBS, barra flotante y backups.

PRIMERA PRUEBA
1. Conserva una copia externa del guardado.
2. Ejecuta preparar_motor.bat.
3. Abre el programa y selecciona Blanco 2 / Negro 2.
4. Comprueba equipo, roles y movimientos antes de guardar.
