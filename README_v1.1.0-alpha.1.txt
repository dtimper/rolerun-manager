RoleRun Manager v1.1.0-alpha.1
=================================

PRIMERA VERSIÓN EXPERIMENTAL DE ULTRA SOL / ULTRA LUNA

Esta versión habilita Ultra Sol / Ultra Luna en la pantalla inicial y reutiliza
el motor PKHeX.Core para:

- leer archivos de guardado llamados main;
- mostrar el equipo, movimientos, objetos, habilidades y marcadores;
- filtrar movimientos existentes y utilizables en séptima generación;
- cambiar movimientos;
- escribir los marcadores de los seis roles;
- sustituir el main activo conservando una copia main_anterior_...;
- vigilar el guardado y sincronizar equipo, roles y OBS.

PRUEBA RECOMENDADA
------------------
1. Ejecuta preparar_motor.bat porque esta alpha debe usar el motor actual.
2. Selecciona Ultra Sol / Ultra Luna.
3. Abre el archivo main.
4. Comprueba que los seis Pokémon se leen correctamente.
5. Haz una copia adicional del main antes de la primera prueba de escritura.
6. Cambia un rol y un movimiento, guarda y abre el resultado en el emulador.

Esta es una alpha. No uses el único ejemplar de una partida importante sin una
copia externa hasta validar lectura, escritura y carga dentro del juego.
