RoleRun Manager v0.2.2-alpha.114

Esta versión corrige la bifurcación demostrada entre la navegación por teclado
y por mando. El D-pad usa la misma superficie visible que el teclado, incluido
el paso «QUÉ MOVIMIENTO OLVIDARÁ» del flujo integrado de MT, y una pulsación
corta produce un único desplazamiento. Drafteos muestra un foco marfil visible
sobre sus botones dorados.

Consulta CHANGELOG.md y docs/CURRENT_STATE.md para la evidencia y el estado
funcional vigente.
