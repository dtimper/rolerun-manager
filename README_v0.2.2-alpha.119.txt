RoleRun Manager v0.2.2-alpha.119

Esta versión hace exclusivos los controles de RoleRun durante una sesión BDSP:
cuando la aplicación está en primer plano, Ryujinx no recibe las flechas ni los
botones de aceptar/atrás del teclado o del mando. Al volver al juego, Ryujinx se
reanuda automáticamente.

Consulta CHANGELOG.md y docs/CURRENT_STATE.md para el detalle técnico y el
estado de validación.
