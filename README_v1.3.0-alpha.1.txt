ROLERUN MANAGER v1.3.0-alpha.1
================================

Primera versión experimental con soporte para Pokémon Omega Rubí / Zafiro Alfa.

Incluye:
- ORAS habilitado en la pantalla inicial.
- Detección de guardados main de Omega Rubí y Zafiro Alfa mediante PKHeX.Core.
- Lectura de equipo, sprites, niveles, objetos, habilidades, movimientos y marcadores.
- Cambio de movimientos y roles.
- Filtrado de drafteos según los movimientos utilizables en el guardado.
- 999 Caramelos Raros y 999 Repelentes Máximos.
- Guardado directo como main con copia main_anterior_<fecha>.
- Vigilancia automática, OBS único y barra flotante.

PRIMERA PRUEBA RECOMENDADA
--------------------------
1. Ejecuta preparar_motor.bat una vez.
2. Abre instalar_y_abrir.bat.
3. Selecciona Omega Rubí / Zafiro Alfa y carga el archivo main.
4. Comprueba el equipo antes de guardar cambios.
5. Conserva una copia externa del main durante esta fase experimental.
