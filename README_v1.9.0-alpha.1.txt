ROLERUN MANAGER v1.9.0-alpha.1
================================

Primera versión experimental con soporte para Pokémon Diamante / Perla de Nintendo DS.

Incluye:
- Guardados .sav y .dsv de DeSmuME.
- Lectura y escritura del equipo, movimientos y marcadores de rol.
- Drafteos filtrados para cuarta generación.
- 999 Caramelos Raros, 999 Repelentes Máximos y Dinero Máximo.
- Lectura con DeSmuME abierto y aplicación durante Reset si el archivo está bloqueado.
- OBS, barra flotante, backups y vigilancia automática.

Para la primera prueba conserva una copia externa del guardado y ejecuta preparar_motor.bat.
