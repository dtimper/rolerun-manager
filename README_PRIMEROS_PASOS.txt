ROLERUN MANAGER v0.1 — PRIMER PROTOTIPO

QUÉ HACE ESTA VERSIÓN
- Mantiene el generador de drafteos por roles.
- Presenta una interfaz moderna oscura con detalles dorados.
- Permite seleccionar cualquier archivo de guardado.
- Calcula su tamaño y huella SHA-256.
- Crea una copia de seguridad y comprueba que sea idéntica.
- NO modifica todavía ningún dato del guardado.

PRIMER INICIO
1. Extrae todo el ZIP en una carpeta normal.
2. Haz doble clic en "instalar_y_abrir.bat".
3. En los siguientes usos puedes abrir "abrir_rolerun.bat".

PRUEBA RECOMENDADA
1. Comprueba los cinco roles en Drafteo.
2. En Partida guardada, selecciona una COPIA de SaveData.bin.
3. Pulsa Crear backup verificado.
4. Comprueba el archivo creado en la carpeta backups.

SIGUIENTE FASE
Integrar PKHeX.Core para identificar el juego y mostrar el equipo sin modificar el guardado.
