ROLERUN MANAGER v1.8.0-alpha.1
================================

NOVEDADES
---------
- Soporte experimental para Pokémon Platino.
- Compatible con guardados .sav y .dsv de DeSmuME.
- Lectura y escritura de equipo, movimientos y marcadores de rol.
- Drafteos filtrados para la cuarta generación.
- Utilidades de 999 Caramelos Raros, 999 Repelentes Máximos y Dinero Máximo.
- Lectura con DeSmuME abierto y aplicación de cambios durante Reset cuando el archivo está bloqueado.
- Integración completa con OBS, barra flotante, vigilancia y backups.

PRIMERA PRUEBA
--------------
1. Conserva una copia externa de tu guardado.
2. Ejecuta preparar_motor.bat.
3. Abre instalar_y_abrir.bat.
4. Selecciona Pokémon Platino y el archivo .sav o .dsv.
5. Comprueba el equipo antes de guardar cambios.
