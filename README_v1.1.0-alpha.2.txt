ROLERUN MANAGER v1.1.0-alpha.2
================================

NOVEDADES
- Utilidades de mochila para BDSP y USUM.
- Botón para establecer 999 Caramelos Raros.
- Botón para establecer 999 Repelentes Máximos.
- Ambos cambios entran en la cola, se revisan, se guardan junto al resto y se validan reabriendo el guardado.
- Se mantiene la copia visible del guardado anterior y el backup interno.

IMPORTANTE
Esta versión modifica el motor de guardados. Ejecuta preparar_motor.bat una vez antes de abrirla.
