RoleRun Manager 1.13.0-alpha.21

ORAS / Azahar
- Un Pokémon que entra desde el juego recibe automáticamente un rol antes de mostrarse en RoleRun.
- Sustitución uno por uno: hereda el rol del Pokémon que sale.
- Alta de un nuevo miembro: usa el primer rol libre de izquierda a derecha.
- Ya no aparece una séptima tarjeta SIN ROL por estos cambios del juego.
- Las escrituras automáticas dejan de mostrar el aviso verde “CAMBIO APLICADO”.
- Las actualizaciones de movimientos evitan reconstrucciones innecesarias de la barra flotante y usan un intercambio visual protegido en Equipo para reducir el flicker.
- Si la barra flotante se activa con REVISAR CAMBIOS u otro modal abierto, el modal se suspende y la barra continúa siendo movible/clicable; al volver a RoleRun se restaura.
- F5 continúa disponible como resincronización manual.

Esta alpha mantiene fuera del monitor en tiempo real la reconstrucción completa de las cajas PC y de toda la mochila.
