RoleRun Manager v0.7.0 — Editor de Roles

Novedades:
- Editor visual de roles desde la pantalla Equipo.
- Roles persistentes guardados en cada Run.
- Opción para volver a usar los marcadores del guardado.
- Historial de cambios de rol.
- Dashboard, drafteos y equipo usan el rol asignado en el Manager.

Esta versión no modifica todavía los marcadores dentro del archivo de guardado; la Run conserva la asignación de forma persistente.
