RoleRun Manager v0.5.0-dev — Run Projects Update

NOVEDADES
- Cada guardado queda vinculado automáticamente a un proyecto persistente dentro de runs/.
- Se crea config.json, history.json y la estructura futura de OBS para cada Run.
- Historial persistente de drafteos aplicados.
- Barra superior con estado de la Run activa.
- Tarjetas ampliadas con rol, habilidad y objeto.
- Archivos OBS preparados: vidas, pociones, medallas y drafteos (todavía sin detección automática).

IMPORTANTE
- Los contadores OBS son solo una base estructural; no se actualizan desde el juego todavía.
- Los roles siguen leyéndose de los marcadores del guardado. La edición de roles desde el Manager se añadirá en una versión posterior.
