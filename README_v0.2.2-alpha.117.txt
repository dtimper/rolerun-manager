RoleRun Manager v0.2.2-alpha.117
================================

La primera apertura de una Run BDSP conserva ahora un indicador animado hasta
que Ryujinx entrega la party live con PS y Max PS coherentes y la pantalla final
de Equipo y PC está completamente compuesta.

Un fallo transitorio del primer enlace ya no deja ver tarjetas con valores
provisionales. RoleRun reintenta en segundo plano y solo habilita la interfaz
cuando la fuente live es utilizable.

No se añaden direcciones RAM ni escrituras nuevas.
