ROLERUN MANAGER v1.4.0-alpha.1
================================

Primera versión experimental con soporte para Pokémon X / Y.

Incluye:
- Lectura y escritura del guardado main de X/Y.
- Equipo, movimientos, roles, objetos y habilidades.
- Drafteos filtrados para el juego activo.
- 999 Caramelos Raros y 999 Repelentes Máximos.
- Backups, vigilancia, OBS y barra flotante.
- Nuevas tarjetas desactivadas para Pokémon Platino y HeartGold / SoulSilver,
  preparadas para futuros motores.

Antes de la primera modificación conserva una copia externa del guardado main.
Ejecuta preparar_motor.bat si el motor local todavía no reconoce X/Y.
