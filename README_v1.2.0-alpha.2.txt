ROLERUN MANAGER v1.2.0-alpha.2
================================

NOVEDAD PRINCIPAL
-----------------
OBS usa ahora una única carpeta fija para la partida activa:

Documentos\RoleRun Manager\OBS\ACTIVO

Configura una sola vez en OBS los cuatro archivos TXT y los seis HTML de esa carpeta. Al abrir BDSP, USUM, Sol/Luna o cualquier juego futuro, RoleRun Manager reemplaza automáticamente el contenido de ACTIVO con los datos de la Run seleccionada.

Las carpetas por juego y por Run se conservan como copias internas, pero OBS no necesita apuntar a ellas.

PRIMERA CONFIGURACIÓN
---------------------
Cambia una última vez tus fuentes de OBS para que lean OBS\ACTIVO. Después no tendrás que modificar las rutas al cambiar de juego.
