ROLERUN MANAGER v1.1.0
=========================

VERSIÓN OFICIAL

Juegos compatibles:
- Pokémon Diamante Brillante / Perla Reluciente
- Pokémon Ultra Sol / Ultra Luna

Incluye:
- Lectura y escritura del equipo, movimientos y marcadores de rol.
- Drafteos filtrados por los movimientos utilizables en cada juego.
- Vigilancia automática del guardado y sincronización con OBS.
- Contadores persistentes de vidas, curaciones, medallas y drafteos.
- Utilidades para establecer 999 Caramelos Raros y 999 Repelentes Máximos.
- Copias de seguridad antes de reemplazar el guardado activo.

Próximo juego previsto: Pokémon Sol / Luna. Después: Omega Rubí / Zafiro Alfa.
