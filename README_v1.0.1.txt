ROLERUN MANAGER v1.0.1 · GUARDADO DIRECTO
================================================

Al pulsar GUARDAR CAMBIOS, RoleRun Manager actualiza directamente el guardado activo sin cambiar su nombre.

Ejemplo:
- Guardado activo: SaveData.bin
- Copia anterior: SaveData_anterior_2026-08-06_12-22-30.bin

También se conserva el backup interno de la Run. El archivo preparado se valida antes de sustituir el original y, si la operación falla, se restaura automáticamente la copia anterior.

IMPORTANTE: cierra el juego o vuelve al menú de Ryujinx antes de guardar cambios para impedir que el emulador sobrescriba el archivo mientras RoleRun Manager trabaja.
